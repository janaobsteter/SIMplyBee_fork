## Maintaining citations

Use `surnameYearFirst` keys in `inst/REFERENCES.bib`. Vignettes use Pandoc
citations (`@key` or `[@key]`).
Roxygen help uses Rdpack references to the same file. Regenerate `man/` and
`NAMESPACE` through roxygen; do not edit generated help manually.

The initial inventory includes all named scholarly references found in
`R/`, the vignettes, README, and `inst/CITATION`,
plus the three explicitly referenced web resources.
DOI metadata was resolved from Crossref/DOI records;
web-reference metadata was retained from existing docs.
`inst/CITATION` remains the package's conventional citation entry point.
General software links and incidental explanatory URLs are not treated as papers.
